Blood Abacus

Support

Blood Abacus is a life counter for trading card games. Track life totals, commander damage, and game state across a table of players — each on their own device.

Features

  • Local multiplayer — connect nearby devices over Bluetooth, with no internet connection required
  • Online multiplayer — join a session using a six-digit room code
  • Table Mode — a shared landscape layout for up to eight players, with commander damage tracked per opponent
  • Utilities — dice roller, trigger and stack tracker, combo reference, number randomizer, and game history

Get help

Email support@behindzero.com. We read every message and try to reply within a few business days.

To help us resolve an issue faster, include your device model, iOS version, and whether you were using local or online multiplayer when the problem occurred.

Common questions

Do I need an account?

No. Blood Abacus has no sign-in and no user accounts. You choose a display name when you join a game, and that is all.

Does local multiplayer need internet?

No. Local multiplayer connects devices directly over Bluetooth, so it works anywhere — including venues with poor or no network coverage. Online multiplayer does require an internet connection.

Devices won't connect over Bluetooth

Make sure Bluetooth is enabled on every device, that each player has granted Blood Abacus permission to use Bluetooth, and that all devices are within range of one another. Closing and reopening the app on each device will restart the connection process.

I can't join an online game

Check that the six-digit room code has been entered correctly and that the host's session is still open. Both devices need a working internet connection.

What happens to my game data?

Local multiplayer keeps everything on the participating devices. Online multiplayer stores temporary game state — life totals and your chosen display name — so that all players stay in sync. See the privacy policy for details.
